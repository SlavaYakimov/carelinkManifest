# PR #1 — правки Славы: карточки «Проблемы / Сценарии / Финальная ценность»

Дата проверки: 2026-10-13. Ветка: `site/manifesto`. Merge не выполнялся.

## Что сделано

1. **«Проблемы семьи»** — 6 карточек в гриде `chapter-grid` (Neo Mirai, та же разметка, что у глав): номер, заголовок, тизер, иллюстрация из `tools/challenges.json` (`image`). Клик открывает `#landing-card-dialog` с полным текстом (описание + «Ответ манифеста»). Исходный список сохранён в `.landing-block-legacy` (скрыт, не удалён).

2. **«Сценарии»** — 3 карточки в том же гриде, картинки из `examples[].image`, модалка с полным телом сценария.

3. **«Финальная ценность»** — одна карточка; контент из `ARTICLE.md` после маркера `<!-- landing:finale -->`; модалка с полным текстом и сноской про плейлист.

4. **Позиция «Финальная ценность»** — секция `#final-value` рендерится **после** блока `.layout` (лонгрид + «Об источниках»), **последней** внутри `<main>`, сразу перед футером. В навигации пункт «Ценность» ведёт на `#final-value`.

Скрипты: `assets/landing-cards.js`, стили в `assets/style.css` (`.landing-card-grid*`, `.landing-card-dialog`). Сборка: `python3 tools/build.py`.
