# Hardening pass — landing scroll surfaces

**Date:** 2026-10-14  
**Scope:** Agenda bundle scroll, chapters scroll, hero tabs, detail modal

## Changes

| Area | Hardening |
|------|-----------|
| **Bundle pointer drag** | Track `pointerId`; clear on `pointercancel`, `lostpointercapture`, `blur`; ignore non-primary mouse button |
| **Bundle keyboard** | Arrow L/R on focused stage; Arrow Up/Down/Home/End in side nav; explicit `[data-bundle-focus]` handlers |
| **Bundle math** | `total ≥ 1`; scroll position uses `max(total - 1, 1)` denominator |
| **Live regions** | `role="status"` + `aria-live="polite"` on bundle/chapter counters |
| **Media queries** | Re-sync scroll stage on `prefers-reduced-motion` / mobile breakpoint changes |
| **Chapters nav** | Arrow/Home/End keyboard between `[data-chapter-goto]` buttons |
| **Hero tabs** | `aria-controls="hero-tab-panel"` on each tab |
| **Detail modal** | Single `close` handler path — restore focus without re-entering `dialog.close()` |

## Residual / out of scope

- **No-JS:** Mobile horizontal scroll still works; desktop scroll-jack requires JS (by design for Make parity).
- **Network:** Static site; no fetch retry paths.
- **Long copy / i18n:** CSS already uses `overflow-wrap` / `clamp()` on agenda; full German expansion pass not run.
- **Chapter longread dialog:** See `assets/chapters.js` (separate from this pass).

## Verify

- Keyboard-only: tab to bundle arrows, nav chain buttons, chapter panel; use arrow keys.
- Touch: drag bundle on desktop pointer; on mobile use native horizontal scroll.
- Modal: open detail from values/skills card, Escape, focus returns to trigger.
